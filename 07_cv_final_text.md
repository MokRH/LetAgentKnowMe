## Research profile
Researcher in metaheuristic computing and stochastic optimisation. My doctoral work developed two enhanced smoothed functional algorithms for data-driven modelling and control, benchmarked against PSO and simulated annealing. Nine selected publications (full list on Scopus/ORCID), three in Q1 journals, six as first author. My problems are black-box, derivative-free optimisation tasks, the same class that search-based software engineering addresses. I am now applying this expertise to software testing, maintenance, security and AI for software engineering.

**Research interests.** Established: metaheuristic computing and stochastic optimisation; data-driven modelling and system identification. Developing: search-based software engineering (testing, maintenance and security); machine learning for software engineering.

## Education

Thesis: *Data-Driven Tool Using Enhanced Smoothed Functional Algorithm for Nonlinear Modeling and Advanced PID Control Problems.* Proposed a norm-limited (NLSFA) and a comparative-memory (CMSFA) variant of the smoothed functional algorithm, tested on twin rotor, flexible manipulator, FOPID-AVR and MIMO gantry crane problems against PSO and SA, with Function of Demerit improvements of up to 62.62%.

## Research contributions
- **Smoothed functional algorithm variants** (memory-based, norm-limited update vector, comparative memory) for PID and fractional-order PID tuning, wind turbine speed regulation and Hammerstein system identification (papers 1, 3, 4, 6).
- **Metaheuristic tuning:** improved marine predators algorithm for fractional-order PID control of an automatic voltage regulator (paper 2).
- **Stochastic and metaheuristic search for wind farm optimisation:** random search variants, including MR-ORSSRS for real-time, high-dimensional power maximisation (papers 5, 7, 9), and the spiral dynamic algorithm (paper 8).
- **Open research code (MATLAB):** github.com/MokRH/Metaheuristic-AVR, fractional-order PID tuning of an AVR system with four smoothed functional variants (SFA, MSFA, NLSFA, CMSFA), accompanying paper 3 (MSFA); github.com/MokRH/Metaheuristic-BenchmarkFunction, MSFA (paper 3) and CMSFA compared with the Whale Optimization Algorithm on the 23 standard benchmark functions.
