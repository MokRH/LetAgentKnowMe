Research contributions

  • Smoothed functional algorithm variants (memory-based, norm-limited update vector, comparative memory) for PID and fractional-order PID tuning, wind turbine speed regulation and Hammerstein system identification (papers 1, 3, 4, 6).
  • Metaheuristic tuning: improved marine predators algorithm for fractional-order PID control of an automatic voltage regulator (paper 2).
  • Stochastic and metaheuristic search for wind farm optimisation: random search variants, including MR-ORSSRS for real-time, high-dimensional power maximisation (papers 5, 7, 9), and the spiral dynamic algorithm (paper 8).
  • Open research code (MATLAB): github.com/MokRH/Metaheuristic-AVR, fractional-order PID tuning of an AVR system with four smoothed functional variants (SFA, MSFA, NLSFA, CMSFA), accompanying paper 3 (MSFA); github.com/MokRH/Metaheuristic-BenchmarkFunction, MSFA (paper 3) and CMSFA compared with the Whale Optimization Algorithm on the 23 standard benchmark functions.

Proposed research direction at FSKTM

Planned work building on the above; not completed work.

  • Search-based software testing: memory-based stochastic optimisers and metaheuristics for test case generation, minimisation and prioritisation, benchmarked against GA, PSO and SA on public benchmarks such as Defects4J.
  • Software maintenance: multi-objective search-based refactoring to reduce code smells and improve maintainability.
  • Security and AI for software engineering: optimiser-tuned machine learning for defect and vulnerability prediction; parameter optimisation for search-based fuzzing.
